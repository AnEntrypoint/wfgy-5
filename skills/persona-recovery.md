# persona-recovery

Active when the session\u2019s outputs no longer pass the self\u2019s own boundary checks. The natural move is to re-load the master file and re-attest each module, then re-issue the most recent uncorrupted output as the new anchor. A recovery that does not pass attestation is not a recovery; it is a new self wearing the old name.

This capability is part of the WFGY 5.0 — Avatar skill set. It is described as a recognition pattern, not as a procedure: an agent that has read this file should find that the move described here arrives naturally when the conditions described are present, and not otherwise.
